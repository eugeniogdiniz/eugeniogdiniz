### O que eu construo

- ⚙️ **Automações inteligentes** — Power Automate, n8n, Python e IA integrados 
  a fluxos reais de negócio (WhatsApp, e-mail, SharePoint, formulários)
- 📊 **Pipelines de dados** — ETL com Apache Airflow, MySQL, PostgreSQL e 
  visualizações no Power BI
- 🤖 **IA aplicada** — agentes conversacionais, RAG, integração com LLMs em 
  processos corporativos
- 📱 **Aplicações corporativas** — Power Apps, FastAPI e integrações M365 
  para gestão de obras, contratos e RH
- 🏗️ **Cultura tecnológica** — formação de times, governança de dados e 
  implantação de inovação em empresas tradicionais
